# 雅思单词馆 · IELTS Vocab Lab

浏览器端雅思单词学习站：新词测验、SM-2 记忆复习、口语练习、每日综合评分。

## 打开方式
- https://raw.githack.com/djession/ielts-vocab-lab/main/index.html
- 访问码 PIN：`ielts2026`

## 录入单词
在「录入/管理」只贴英文单词（每行一个）。词性、含义、常见结构搭配、例句由老师在聊天里收到词表后补充。

## 功能
- 英文批量导入（支持词组）
- 新词专项测验 + 批阅（有搭配/例句时会显示）
- SM-2 记忆曲线复习
- Web Speech 口语练习
- 每日综合评分

数据保存在浏览器 localStorage；老师可通过更新仓库 `words.json` 同步释义与搭配。
